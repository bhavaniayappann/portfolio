# Bhavani Ayappann — Portfolio

Modern, minimal portfolio built with Next.js, TypeScript, and Tailwind CSS.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Customize

- Personal links: `data/site.ts` (email, LinkedIn, GitHub, site URL)
- Project copy & case studies: `data/projects.ts`
- Resume: replace `public/resume.pdf` with your real PDF
- Project screenshots (optional): add images under `public/images/`

## Deploy

Push to GitHub and import the repo in [Vercel](https://vercel.com). No special env vars required for the current build.
